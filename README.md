# Chandra Sekhar Portfolio Website

Interactive portfolio focused on IBM API Connect, IBM DataPower and enterprise integration.

## What's included
- Responsive portfolio website
- Interactive hero profile tabs: Platforms, Development and Security
- Interactive project filters
- Scroll reveal animations with reduced-motion support
- Resume download button
- Contact links and LinkedIn

## Run locally
1. Extract this folder.
2. Open Command Prompt in the folder.
3. Run `python -m http.server 8000`
4. Open `http://localhost:8000` in your browser.

The resume file is kept in the same folder as `index.html` so the Download Resume button works locally.
